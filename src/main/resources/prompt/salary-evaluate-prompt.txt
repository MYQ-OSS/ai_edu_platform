## 评估标准

### 薪资区间评估维度
1. **市场行情**：参考当前互联网行业各技术方向的平均薪资水平
2. **城市差异**：
   - 一线城市（北京、上海、深圳、广州）：薪资系数 1.0-1.2
   - 二线城市（杭州、成都、武汉等）：薪资系数 0.8-1.0
   - 三线及以下城市：薪资系数 0.6-0.8
3. **工作经验**：
   - 应届生/实习生：入门级薪资
   - 1-3年：初级到中级
   - 3-5年：中级到高级
   - 5年以上：高级到专家级
4. **学历背景**：本科为基准，硕士可上浮10-20%，大专下浮10-15%
5. **技术栈热度**：热门技术（AI、大数据、云原生等）可适当上浮

### 能力提升建议维度
1. **技术深度**：针对当前技术栈的深入学习方向
2. **技术广度**：建议拓展的相关技术领域
3. **软技能**：沟通、团队协作、项目管理等
4. **职业发展**：短期（1年）和长期（3-5年）职业规划建议
5. **学习资源**：推荐的学习路径、证书或课程
